# Purpose

Creates a new [Vehicle](/models/vehicle.md): name, make, model, year, plate number, and
starting odometer. On save it calls `addVehicle` on the
[RecordsProvider](/state/records-provider.md). Reached from
[VehiclesScreen](/screens/vehicles-screen.md).
